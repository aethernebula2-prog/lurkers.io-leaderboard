How to Report Player

This guide explains how to report players for rule violations in Lurkers.io.

What Can I Report?

Griefing Breaking friendly blocks, blocking teammates on purpose.
Highly Offensive Using offensive language, Racism or discrimination to other players.
Votekicking Votekick random people without any reason.
Hacking Using hack in game to compromise the competitive integrity.

How to Report?

If you see a player breaking the rules, you can report them through the official Lurkers.io Discord server.

You can enter the official server from the bottom-right corner of lurkers menu.

  1. Go to the #report-players channel in Discord server.
  2. Use @Support in your message.
  3. Include the following information:
    • Griefer name: Player's name.
    • PlayFab ID: The player's PlayFab ID.
    • Server name: The server where it happened.
    • Description: Explain what happened.
    • Additional: Screenshots, video, or other evidence.
  4. Check your report and send it.
Tip: Don't just mention @Support-latino

How to get PlayFab ID?

Right click player's name in the Scoreboard, and click View account

Then, click View JSON to copy that player's PlayFab ID.

Example of JSON

{
              "PlayFabId": "XXXXXXXXXXXXXXX",
              "InfoResultPayload": {
                "AccountInfo": {
                  "PlayFabId": "XXXXXXXXXXXXXXX",
                  "Created": "YYYY-MM-DDTHH:MM:SS.MSZ",
                  "TitleInfo": {
                    "Created": "YYYY-MM-DDTHH:MM:SS.MSZ",
                    "TitlePlayerAccount": {
                      "Id": "...",
                      "Type": "title_player_account",
                      "TypeString": "title_player_account"
                    }
                  }
                },
                "UserData": {},
                "UserDataVersion": 0,
                "UserReadOnlyData": {},
                "UserReadOnlyDataVersion": 0
              }
            }

Outcome

After you send your report, a support with [SUP] will arrive the server. If necessary, they may ban the reported player for 24 hours.

Remember: Support may use alts to avoid alerting the reported player.
Remember: Support can only issue a maximum 24-hour ban per player, Moderators reserve the right to permanently ban players at their discretion.
